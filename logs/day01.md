# Day 1: Finding the centre

**Learned:** Mean, median and mode each answer "what's typical?" differently. The mean feels every value, so one outlier drags it; the median only cares about the middle; the mode is the only one that works for categories.

**Surprised me:** Why the median salary is what gets reported: one CEO can make the mean describe nobody.

**Mistake:** I copied the data wrong (dropped a repeated value), which changes the mean. Step zero is copying the data exactly.
